# ⚠️  macOS-Specific Notes:
# 
# 1. PYTORCH INSTALLATION (MPS Compatible):
#    DO NOT use "pip install torch" - it won't have MPS support
#    Instead use official PyTorch wheel:
#    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
#
# 2. NO NVIDIA GPU / NO CUDA:
#    • We use CPU execution provider for ONNX Runtime
#    • MPS is used for PyTorch operations
#    • CodeFormer works on CPU/MPS
#    • Real-ESRGAN works on CPU/MPS
#
# 3. REMOVE CUDA-ONLY PACKAGES:
#    • nvidia-ml-py  ← REMOVED (no NVIDIA GPU)
#    • pynvml  ← REMOVED (NVIDIA monitoring, not needed)
#
# 4. MODEL DOWNLOADS (Manual Required):
#    Before using High Quality / Ultra modes, download models:
#
#    CodeFormer:
#    wget -O ~/.cache/codeformer/codeformer.pth \
#      https://github.com/sczhou/CodeFormer/releases/download/v0.1.0/codeformer.pth
#
#    Real-ESRGAN 2x Compact:
#    wget -O ~/.cache/realesrgan/RealESRGAN_x2_compact.pth \
#      https://github.com/xinntao/Real-ESRGAN/releases/download/v0.2.5/RealESRGAN_x2_compact.pth
#
# 5. MEMORY SETTINGS (M1 Pro 16GB):
